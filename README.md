### plugin.video.rezka - Плагин для ОС Kodi
Аддон для просмотра фильмов и сериалов
<br>Разработан и протестирован на ОС Kodi
<br>Просьба поставить звезду, если Вы решили использовать данный плагин
<br>Так я буду знать, сколько пользователей нуждаются в развитии проекта

======================================================================================

### Описание:
##### Категории:
- Лента последних поступлений
- Поиск

##### Функционал:
- Выбор озвучки
- Выбор качества
- Просмотр описания

##### Настройки:
- Возможность изменения адреса ресурса
- Авторизация: Email и Password
- Выбор качества по умолчанию и отображаемых дополнительных тегов

======================================================================================

### Установка:
1) Скачать zip-архив
2) Скопировать zip-архив на устройство с ОС Kodi через ssh или флэшкой
3) В ОС Kodi, в разделе Add-on произвести установку из файла (если выдает ошибку, то необходимо перезагрузиться)
4) Запустить установленный аддон в том же разделе -> зайти в настройки и ввести данные авторизации, либо можно внести настройки до запуска приложения

======================================================================================

### Возможные ошибки
- Удалите в имени архива "kodi.", чтобы осталось только "plugin.video.rezka.zip"
